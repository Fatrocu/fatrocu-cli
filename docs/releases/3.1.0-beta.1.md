# Fatrocu CLI 3.1.0-beta.1

**Beta preview — real-data accuracy has not been validated.** The private extraction benchmark is **NOT RUN (dataset pending)**. Neither the e-Archive nor the OKC Z-report/UTTS accuracy gate has passed. No real-data accuracy scores are available, and passing synthetic tests or model connectivity checks does not establish extraction accuracy.

Our next milestone is to complete the private benchmark as soon as the human-reviewed dataset is ready, fix any findings, and publish the stable **3.1.0** release after both document-family gates and the remaining release checks pass. There is no confirmed publication date; this beta is not a promise of a benchmark pass.

These downloads are **unsigned beta test builds for manual use**, not verified production updates. The signing identity and real signed-installation validation remain pending. SHA-256 checksums detect corrupted downloads; they do not authenticate a publisher. Stable update discovery continues to exclude prereleases, and signature verification is unchanged.

Keep original financial documents, reviewed labels, API credentials and raw telemetry local. Review and approve every document before export. Unreadable values must remain blank/null with a review flag; never treat a plausible value as verified.

## What is available

- Shared Rust core used by the CLI and Windows desktop.
- e-Archive invoice, OKC Z-report and UTTS workflows with deterministic parsing and optional local/remote model extraction.
- Taxpayer profiles, nullable source-grounded fields, exact tax merging, revision-safe correction and individual approval.
- Local SQLite storage, retained originals, backups and approved-only Excel/CSV/JSON exports.
- Explicit disclosure and per-import consent before sending document contents to a non-loopback inference service.

## Download and run

Choose the unsigned Windows x86_64 or Linux x86_64 ZIP from this release and compare its SHA-256 with the accompanying checksum file. Extract to a new directory, separate from your existing installation. On Linux, run `chmod +x fatrocu-cli` if your extraction tool does not retain executable permissions. Check `fatrocu-cli --version` and `fatrocu-cli --help`. Source builds use `cargo build --locked --release`.

Use the matching [fatrocu-server beta](https://github.com/Fatrocu/fatrocu-server/releases/tag/3.1.0-beta.1) to set up the local model. PDF previews and scanned-PDF inference require Poppler `pdftoppm` on PATH; `pdftotext` is optional for word coordinates. Model weights, runtime downloads and private documents are not bundled.
